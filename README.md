


# 📚 Word Trainer

**Word Trainer** is an interactive web application for learning new words.  
It helps you expand your vocabulary with flashcards, track your progress, and view detailed learning statistics.

---

## 🚀 Features

- 🧠 View words in **random** or **sequential** order  
- 📈 Track progress with real-time statistics:  
  - Total words  
  - Learned words  
  - Remaining words  
- 💾 Automatically saves progress in **LocalStorage**  
- 🎨 Responsive and modern UI built with **TailwindCSS**

---

## 🏗️ Technologies

| Category | Tools |
|-----------|--------|
| ⚛️ Frontend | React + Vite |
| 🎨 UI | TailwindCSS |
| 🧩 Architecture | Atomic Design (atoms / molecules / organisms) |
| 💾 Data Storage | LocalStorage |
| 🧰 Card Logic | `CardManager` class for managing state and progress |

---

## 📦 Installation & Run

### 🔧 1. Clone the repository
```bash
git clone https://github.com/username/word-trainer.git
cd word-trainer
````

### 📥 2. Install dependencies

```bash
npm install
```

### ▶️ 3. Run the app in development mode

```bash
npm run dev
```

Then open in your browser:

```
http://localhost:5173/
```

### 🏗️ 4. Build for production

```bash
npm run build
```

### 🌐 5. Preview the production build

```bash
npm run preview
```
